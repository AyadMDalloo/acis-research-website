# ACIS Research Website

A responsive, dynamic academic research-group website inspired by the information architecture of a conventional laboratory site, but redesigned from scratch with a modern visual system.

## Files
- `index.html` — content and page structure
- `style.css` — responsive design, dark/light themes, animation and layout
- `script.js` — navigation, scroll effects, filters, counters, publication search and hero network animation

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the initials-based member placeholders with verified profile photos if desired.
3. Confirm the exact academic role and biography for Sulaf Waiss.
4. Replace the sample research-manuscript entries with verified publications and DOI/IEEE/Scopus/Google Scholar links.
5. Change `ACIS Research Group` if you prefer a different official group/laboratory name.

## How to run
Open `index.html` directly in a browser. No build tools or external JavaScript libraries are required.

For local development, VS Code + Live Server is convenient but optional.

## Publishing options
The site can be published on GitHub Pages, Netlify, Cloudflare Pages, university hosting, or any normal web server.
